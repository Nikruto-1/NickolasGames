# Timer audio

- `holmes-time-up-uk.mp3`: recording supplied by the project owner; converted from M4A to mono MP3 and loudness normalized.
- `holmes-meow.mp3`: Kerzoven, "Cat Purr & Meow", `cat_mewfood.wav`, CC0. Source: https://opengameart.org/content/cat-purr-meow — https://opengameart.org/sites/default/files/cat_mewfood.wav. Converted to mono MP3, high-pass filtered and loudness normalized.

Ukrainian uses the spoken recording. All other languages use the cat meow. Both are bundled and cached for offline play.
