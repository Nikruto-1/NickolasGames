# Timer audio

- `holmes-time-up-uk.mp3`: recording supplied by the project owner; converted from M4A to mono MP3 and loudness normalized.
- `holmes-meow.mp3`: `animals-cat-blue-meow.mp3`, supplied by the project owner and copied without audio processing.

Ukrainian uses the spoken recording. All other languages use the cat meow. Both are bundled and cached for offline play.
